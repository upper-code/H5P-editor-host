# Permission to use VMB libraries

On 2026-10-30 the project maintainer confirmed that the developers of
`VMB.InteractiveBook`, `VMB.Column` and `VMB.Adapt` authorized their use inside
an H5P book, provided that their source code is not modified and no derivative
products are created from these libraries.

This records the permission reported by the maintainer. It is a limited
permission for that use, not an open-source license or permission to modify,
fork or use these libraries to create derivative products. Editing the book's
content does not itself change the libraries' source code.

Keep the libraries' existing copyright and third-party notices. Their
`library.json` declarations remain unchanged, including missing licenses and
the `cr` copyright marker. Any separately applicable public licenses retain
their own terms; this record does not replace them or grant an exception to
the GPL or other licenses of H5P, CKEditor or this host.

The license inventory repeats this scope so that a library bundle carries the
record with it. Versioned reviewed exceptions identify known VMB artifacts
whose metadata does not state a license; they do not authorize modified
libraries or uses outside the permission above. Keep the developers' original
permission with the deployment's licensing records.
